# v1.56.0 — 3 novembre 2026

lilOS 1.24.0: **impostazioni di installazione** (`lilos-install.json`) e **immagini del sistema**. Le app non cambiano. Il programma lilOS con questa versione si scarica dalle release del repository lilOS: https://github.com/GexyLab/lilos/releases (`release-v1.24.0`, «lilOS 1.24.0»).

## lilOS 1.23.0 → 1.24.0

- **Nuova funzionalità — impostazioni di installazione.** Un file `lilos-install.json` dice a chi installa lilOS (`tools/install.js --settings <file>` o il programma lilOS) dove installarlo, se usare il lilOS portato dall'installer o il più recente del repository ufficiale, quali moduli (portati o del server) e con quale configurazione (per esempio il database di fs-postgres), quali repository aggiungere, quali app installare (anche da repository non ufficiali), quali utenti creare e con quali impostazioni iniziali (tema, colore, sfondo…). Al primo avvio il kernel crea utenti e app, poi segna il file come applicato e **toglie le password**. Le impostazioni iniziali valgono anche per gli utenti creati dopo. *Perché:* installare lilOS già pronto per un ufficio o una scuola, senza passare a mano dal Pannello di controllo e dall'AppStore.
- **Nuova funzionalità — immagini del sistema.** `tools/image.js` fa un'immagine di un lilOS installato e configurato (versioni, configurazione, moduli con i loro dati, app installate, utenti e i file delle loro home); con `"image"` nel file di installazione si installa quella al posto della release ufficiale: una cartella, un `.zip`/`.tar.gz` o un indirizzo http(s). Le sessioni aperte non entrano mai nell'immagine. *Perché:* copiare un sistema già configurato su altri computer.
- **Sicurezza.** Nel file di installazione le password stanno solo fino al primo avvio: il kernel le cancella dalla sua copia. Un'app non verificata si installa dal file solo con `"allowUnsigned": true` scritto per quell'app (l'equivalente di accettare l'avviso dell'AppStore).

## Come aggiornare

AppStore → Aggiornamenti → lilOS, poi riavvio del kernel. Le impostazioni di installazione servono solo alle nuove installazioni.
