# v1.61.0 — 5 novembre 2026

## lilOS 1.32.0 → 1.33.0 (SDK 0.20.0 → 0.21.0)

- **Nuova funzionalità — file fino a 1 GB.** Il limite di 10 MB per file non c'è più: il kernel salva i file a flusso, senza tenerli in memoria, e il predefinito è 1 GB. Un amministratore lo cambia in Pannello di controllo → Archiviazione → Limiti; con 0 non c'è limite. *Perché:* video, archivi e immagini disco non entravano in lilOS.
- **Nuova funzionalità — quota di spazio per utente.** Una quota predefinita per tutti (0 = senza limite, come prima) e quote personali per singoli utenti, in Archiviazione → Utenti. Contano tutti i file della home, cestino compreso. Oltre la quota si rifiutano solo le scritture che fanno crescere lo spazio: cancellare, svuotare il cestino o rimpicciolire un file si può sempre, e lilOS salva sempre le proprie impostazioni. Al 90% arriva una notifica che apre Archiviazione. *Perché:* con file grandi un utente poteva riempire il server.
- **Nuova funzionalità — Il mio spazio.** Ogni utente vede in Archiviazione lo spazio usato, la sua quota e la dimensione massima di un file.
- **Nuova funzionalità — caricamenti a pezzi riprendibili.** I file più grandi di 8 MB vanno dal browser al kernel in più richieste; un invio interrotto dalla rete riparte dal punto in cui era arrivato.
- **Miglioramento — soglie configurabili.** Lettura di un file intero in memoria (256 MB), testo (10 MB), file piccoli in una riga del database (1 MB), pezzi nel database (1 MB), copia dei file nel browser (fino a 10 MB: i file grandi non riempiono più il browser) e pezzi di caricamento (8 MB). Ogni valore mostra se è quello predefinito o è stato modificato e si ripristina con un clic. Si possono dare anche all'installazione (`lilos-install.json` → `kernel.settings`).
- **SDK 0.21.0.** Nuovo `kernelSettings` (`limits()`, `list()`, `update()`, `users()`); per i moduli del kernel `ctx.settings` e il metodo facoltativo `fs.usage()`; nuovo codice d'errore `quota` (HTTP 507).

## Pacchetti di lingua 1.0.0 → 1.1.0 (tutte le 20 lingue, richiedono lilOS ≥ 1.33.0)

- **Miglioramento:** i nuovi messaggi del kernel (limiti, quote, caricamenti, impostazioni) tradotti. Per hindi, urdu, arabo e greco resta consigliata una revisione di madrelingua.

## App

- **Pannello di controllo 1.21.0 → 1.22.0** — *Nuova funzionalità:* Archiviazione con le sotto-schede Il mio spazio, Limiti e Utenti (le ultime due solo per gli amministratori). Su un lilOS più vecchio la scheda resta com'era. *Correzione bug:* le voci «App Microsoft» e «Progetto Google» non compaiono più due volte tra le sezioni che si possono aprire (per esempio in Automata).

## Moduli del kernel

- **fs-postgres 1.1.1 → 1.2.0** — *Nuova funzionalità:* dice al kernel lo spazio usato da ogni utente (serve per le quote) e segue le impostazioni del kernel per i pezzi e la lettura in memoria. *Miglioramento:* i file piccoli restano in una riga sola, quelli grandi vanno in pezzi anche quando arrivano interi; la dimensione dei pezzi si salva con ogni file, quindi cambiarla non tocca i file già scritti. Con lilOS 1.33.0 senza questo aggiornamento non ci sono quote.
- **netfs-s3 1.1.0 → 1.2.0** — *Miglioramento:* invio unico e dimensione delle parti configurabili (predefiniti come prima: 16 MB e 16 MB).
- **netfs-azblob 1.1.0 → 1.2.0** — *Miglioramento:* invio unico e dimensione dei blocchi configurabili (32 MB e 8 MB).
- **netfs-google 1.0.0 → 1.1.0** — *Miglioramento:* dimensione dei pezzi di caricamento su Drive configurabile (8 MB).
- **netfs-onedrive 1.2.0 → 1.3.0** — *Miglioramento:* dimensione dei pezzi di caricamento configurabile (10 MB).
- **netfs-nfs 1.1.0 → 1.2.0** — *Miglioramento:* byte per lettura e scrittura configurabili (256 KB, mai oltre quanto permette il server).

## Come aggiornare

1. AppStore → aggiorna **lilOS** (poi riavvia il kernel quando lo chiede).
2. Aggiorna il modulo **fs-postgres** (il kernel si riavvia), il Pannello di controllo e la tua lingua; i moduli di rete se li usi.
3. Se davanti a lilOS c'è un proxy (nginx, Apache) con un limite sulla dimensione delle richieste: lilOS manda pezzi da 8 MB. Alza il limite del proxy, oppure abbassa «Pezzi di caricamento» in Archiviazione → Limiti.
4. Le app che leggono un file tutto in memoria hanno i loro limiti (Foto 25 MB, anteprime 20 MB, Compress Archive 256 MB in tutto): per i file più grandi lo dicono loro.
