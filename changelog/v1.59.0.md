# v1.59.0 — 4 novembre 2026

lilOS 1.31.0 e la nuova app **Note adesive** 1.0.0: note colorate sulla scrivania. Nessun'altra app e nessun modulo cambiano.

## lilOS 1.30.0 → 1.31.0

- **Nuova funzionalità — widget sulla scrivania.** Un'app di sistema può mostrare sulla scrivania i file di un suo tipo con un proprio widget, al posto dell'icona. Il widget si seleziona, si sposta, va nelle workarea e nel Cestino come le icone; aprirlo lo modifica sul posto; «Riordina icone» lo lascia dov'è; nella minimappa ha il suo colore. Senza l'app, o scegliendo un'altra app per quel tipo di file (Pannello di controllo → Usabilità → Tipi di file), i file tornano icone subito. *Perché:* serviva per le note adesive; i widget erano accettati nel manifesto ma non si vedevano.
- **Nuova funzionalità — Nuovo → Nota adesiva** nel tasto destro della scrivania, quando Note adesive è installata. *Da sapere:* chi aveva già personalizzato quel menu la vede dopo averlo ripristinato (Pannello di controllo → Usabilità → Menu contestuale).
- **Per gli sviluppatori — SDK 0.18.0 → 0.19.0** (compatibile): `fs.everywhere(test)` elenca i nodi di tutti i workspace in sola lettura, `fs.bring(id, cartella)` porta un nodo da un altro workspace, le azioni di `menus` possono avere `visible`, nuovo glifo `note`. `@lilos/system` ha `revealOnDesk`, `bringToDesk`, `newWidgetOnDesk` e `widgetFor`. Il manifesto accetta `contributes.widgets[].fileType` (uno dei `fileTypes` dell'app); il permesso `desktop.widget` ora ha effetto, per le app di sistema.

## Note adesive (nuova) 1.0.0 — richiede lilOS ≥ 1.31.0

- **Nuova funzionalità — note sulla scrivania.** Foglietti in sei colori, da scrivere lì sopra con doppio clic o Invio: la prima riga è il titolo, `- ` fa un elenco, `- [ ] ` una casella da spuntare (anche con un clic, senza scrivere), `**testo**` il grassetto. La misura si cambia dall'angolo o dal menu. Da lontano si vede solo il titolo, più grande. Una nota nuova lasciata vuota sparisce.
- **Nuova funzionalità — promemoria.** La campanella propone tempi rapidi o una data e un'ora; arriva come notifica anche a lilOS chiuso (con il modulo `scheduler`, che ogni lilOS ha) e un clic mostra la nota, cambiando workspace se serve.
- **Nuova funzionalità — tutte le note in una finestra.** Le note di tutti i workspace, anche quelle nascoste in una workarea ridotta: ricerca, filtri per workspace, colore e promemoria, **Mostra** e **Porta qui**.
- **Le note sono file.** Ogni nota è un file di testo `.sticky` nella cartella Scrivania: Cestino, Ctrl Z, File Manager (con l'anteprima), Editor e copie funzionano come per gli altri file. In inglese e in italiano.

## Come aggiornare

1. AppStore → **Aggiornamenti** → aggiorna **lilOS** e riavvia quando l'AppStore lo chiede.
2. AppStore → installa **Note adesive** (Produttività). Poi tasto destro sulla scrivania → Nuovo → Nota adesiva.
